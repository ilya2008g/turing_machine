# Машина Тьюринга (симулятор)

Программа с графическим интерфейсом для моделирования детерминированной машины Тьюринга.
Позволяет задавать алфавиты, строку на ленте, таблицу переходов и наблюдать за пошаговым или
автоматическим выполнением алгоритма.

## Возможности

- Два непересекающихся алфавита: **основной** (символы строки) и **дополнительный** (рабочие символы).
- Визуальная лента с отображением текущего положения головки.
- Редактируемая таблица переходов:
  - Добавление и удаление состояний (кнопки `+` / `-`).
  - Ячейки принимают команды в формате: `новый_символ, направление (L/R), новое_состояние` или `!` для останова.
- Управление симуляцией:
  - ▶ **Старт** – автоматическое выполнение с заданной скоростью.
  - ⏯ **Шаг** – один такт машины.
  - ⏸ **Пауза** – приостановка автоматического выполнения.
  - ⏹ **Стоп** – сброс симуляции к исходной строке.
- Регулировка скорости (кнопки `+` / `-` в секции «Скорость»).
- Возможность изменить алфавиты в любой момент с сохранением совместимых правил (кнопка «Изменить алфавиты»).

## Сборка и запуск

Для сборки требуется компилятор C++ и библиотека Qt (версия 5 или 6). Рекомендуемый способ — **qmake**.
